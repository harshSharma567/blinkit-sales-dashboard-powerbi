# Blinkit Sales Performance Dashboard

## Project Overview

Developed an interactive Power BI dashboard to analyze Blinkit's sales performance, inventory distribution, and customer satisfaction using 8,523 grocery transactions. Leveraged Power BI, Power Query, and DAX to transform raw data into actionable business insights through interactive visualizations and KPI reporting.

---

## Dataset

- **Dataset:** Blinkit Grocery Sales Dataset
- **Source:** Microsoft Excel
- **Records:** 8,523 grocery transactions
- **Fields:** 12 business attributes

---

## Project Objectives

- Monitor key business KPIs.
- Analyze sales trends and outlet performance.
- Evaluate product category performance.
- Identify customer buying patterns.
- Support data-driven business decisions.

---

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel

---

## Dashboard Features

- KPI Cards (Total Sales, Average Sales, Number of Items, Average Ratings)
- Interactive Slicers (Outlet Size, Outlet Location, Item Type)
- Line Chart for Sales Trend Analysis
- Donut Charts for Sales Distribution
- Bar Charts for Product & Outlet Analysis
- Funnel Chart for Outlet Location Performance
- Matrix Visual for Outlet-wise KPI Comparison
- Dynamic Field Parameters for KPI Switching

---

## Key DAX Measures

- Total Sales
- Average Sales
- Number of Items
- Average Rating

---

## Data Preparation

- Cleaned and standardized raw Excel data using Power Query.
- Corrected inconsistent categorical values.
- Built reusable DAX measures for business KPIs.
- Modeled data for interactive reporting and analysis.

---

## Business Insights

- Tier 3 outlets generated the highest total sales.
- Medium-sized outlets outperformed small and large outlets.
- Fruits & Vegetables were the highest-selling product category.
- Overall customer rating averaged **3.9/5**.
- Dashboard enables dynamic filtering across outlet size, location, and item type.
